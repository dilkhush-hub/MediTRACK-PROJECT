MediTrack Three.js feature

Keep these four files in the same project folder:
- medi.html
- medi.css
- medi.js
- three-scene.js

The existing medi.js features are preserved. three-scene.js loads Three.js from jsDelivr,
so an internet connection is required when viewing the 3D model.

Run medi.html with VS Code Live Server or deploy all four files to Netlify.
Use the sidebar's "3D Hospital" link. Drag to rotate, scroll to zoom, and use the
buttons to reset or pause/start automatic rotation.
